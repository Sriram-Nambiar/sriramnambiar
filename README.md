# Sriram Nambiar — Portfolio

A minimal, dark-mode developer portfolio showcasing full-stack projects, systems engineering, and open-source contributions.

---

## ⚡ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Widgets:** [react-github-calendar](https://github.com/grubersjoe/react-github-calendar)
- **Runtime / Package Manager:** [Bun](https://bun.sh/)

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sriram-Nambiar/portfolio.git
cd portfolio
```

### 2. Install dependencies

```bash
bun install
# or: npm install
```

### 3. Run development server

```bash
bun dev
# or: npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Build for Production

```bash
bun run build
bun start
```
